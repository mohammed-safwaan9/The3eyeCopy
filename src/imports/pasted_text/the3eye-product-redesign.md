==================================================

The provided The3eye app icon is the OFFICIAL BRAND IDENTITY.

The official The3eye logo should be used only where branding naturally belongs:

- splash screen
- onboarding
- authentication

The map does not need the logo.
Every button does not need the logo.

A strong brand does not need to constantly advertise itself.

Let the DESIGN SYSTEM communicate The3eye.

REDESIGN THE MAP ITSELF.

Do not simply place prettier UI on top of the existing map.

Create a professional navigation-map aesthetic.

The map should have:

- realistic road hierarchy
- primary roads clearly distinguished
- secondary roads quieter
- minor streets subtle
- intersections with proper geometry
- restrained building shapes
- subtle parks
- subtle water
- intelligent label hierarchy
- realistic geographic density

NOT a black background with lines drawn over it.

Avoid fake 3D.

Avoid neon roads.

Avoid glowing roads.

Avoid unnecessary gradients.

The map should be visually calm so live reports become the focus.
