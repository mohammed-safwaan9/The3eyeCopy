==================================================
1. DESIGN PHILOSOPHY
==================================================

Design the product around one principle:

"Everything that helps the driver should be immediately understood.
Everything that does not help the driver should disappear."

Prioritize:

1. Usability
2. Visual hierarchy
3. Map quality
4. Typography
5. Iconography
6. Consistency
7. Information density
8. Interaction quality
9. Brand identity
10. Visual polish

Do not add decoration just to make screens look impressive.

Every element must have a purpose.

If an element does not improve understanding, navigation, safety or interaction, remove it.

If something can be communicated with one element instead of three, use one.

If an interaction can be reduced by one tap, reduce it.
